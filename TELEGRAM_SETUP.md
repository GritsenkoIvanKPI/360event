# Форма «Залишити заявку» → Telegram

Форма в секції `#request` на `index.html` надсилає заявки в Telegram. Токен бота
**ніколи** не потрапляє в `index.html` — інакше будь-хто прочитав би його через
«переглянути код сторінки». Токен живе тільки на сервері, у файлі `config.php`.

```
браузер  →  send-form.php  →  api.telegram.org
                  ↑
             config.php  (токен, у git не потрапляє)
```

## 1. Створити бота

1. У Telegram відкрити [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Задати назву та юзернейм.
3. BotFather віддасть токен виду `1234567890:AAF…`. **Нікому не пересилати** —
   ні в чат, ні на пошту.

## 2. Дізнатися `chat_id`

1. Створити групу (напр. «Вебінар 360 — заявки») і додати в неї бота.
2. Написати в групу будь-яке повідомлення.
3. Відкрити в браузері `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
4. Знайти у відповіді `"chat":{"id":-100…}` — це і є `chat_id`.

`chat_id` сам по собі нешкідливий: без токена в цю групу ніхто не напише.

## 3. Завантажити файли на Hostinger

```
node build-deploy.mjs
```

Команда створює теку `deploy/` і архів `deploy.zip` — рівно те, що має лежати в
`public_html/`, і нічого зайвого. Далі: hPanel → File Manager → `public_html` →
Upload → `deploy.zip` → розпакувати (або перетягнути вміст `deploy/` по FTP).

**Не заливати нічого іншого з репозиторію.** Усе, що потрапить у `public_html`,
читається ззовні за прямим посиланням (брифи, логопак, оригінали фото).

## 4. Створити `config.php`

Через File Manager у hPanel створити `public_html/config.php`
(зразок — `config.example.php`):

```php
<?php
return [
    'bot_token' => 'сюди токен від @BotFather',
    'chat_id' => '-100xxxxxxxxxx',
    'notify_email' => '',
    'rate_limit_per_hour' => 5,
];
```

Створювати **прямо на сервері**. У git цей файл не потрапляє — він у `.gitignore`.

## 5. Перевірити

Спочатку самодіагностика — відкрити в браузері:

```
https://360webinaruaoa.online/send-form.php?selftest=1
```

Має бути `"config_present": true`, `"token_present": true`, `"can_send": true`
і ваш `chat_id`. Токен там не показується — тільки його довжина.

Потім надіслати тестову заявку з сайту. У групу має прийти повідомлення, а на
сторінці — зʼявитися «Дякуємо, заявку надіслано». Якщо ні — дивитись error log
у hPanel, `send-form.php` пише туди причину.

## Що вміє форма

- поля: імʼя, телефон (обовʼязкові), email і коментар (необовʼязкові), згода на
  обробку даних;
- перевірка і в браузері, і на сервері;
- прихована пастка для ботів (поле `website` — людина його не бачить);
- ліміт заявок за годину з однієї IP (`rate_limit_per_hour`);
- необовʼязкова копія заявки на пошту (`notify_email`);
- повідомлення про помилку ніколи не розкривають токен.

## Безпека

- Токен не пересилати в чаті чи поштою. Якщо витік — у @BotFather зробити
  `/revoke`, отримати новий і переписати `config.php`.
- `config.php` ніколи не комітити. `.htaccess` додатково забороняє віддавати його
  напряму.

## 6. Домен — що перевірити

1. **SSL** — увімкнути безкоштовний сертифікат у hPanel: усі адреси сайту
   починаються з `https://`.
2. **`.htaccess`** — лежить у `deploy/`, перенаправляє `http://` і `www.` на
   `https://360webinaruaoa.online`.
3. **Google Search Console** — підтвердити домен і подати `sitemap.xml`.
